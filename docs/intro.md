# Introducción

## Descripción

**TaskFlow** es una aplicación web ficticia destinada a la gestión de tareas y pequeños proyectos de forma sencilla.

El sistema permite a los usuarios crear proyectos, organizar tareas, asignar responsables y consultar el estado de cada actividad.

El proyecto está planteado como una aplicación web desarrollada con tecnologías modernas y preparada para ser desplegada mediante GitHub Pages.

## Objetivos

Los principales objetivos de TaskFlow son:

- Facilitar la organización de tareas.
- Permitir agrupar tareas dentro de proyectos.
- Mostrar el estado de las actividades.
- Mantener una estructura de código sencilla y mantenible.
- Aplicar técnicas de diseño orientado a objetos.
- Incorporar pruebas automatizadas.
- Disponer de documentación técnica del proyecto.

## Alcance

La primera versión incluye:

- Gestión de proyectos.
- Creación y edición de tareas.
- Asignación de tareas a usuarios.
- Estados de tarea.
- Fechas de vencimiento.
- Filtrado de tareas.
- Persistencia de los datos en el navegador.

Quedan fuera del alcance de esta versión:

- Autenticación mediante servidor.
- Aplicación móvil nativa.
- Notificaciones por correo electrónico.
- Integración con servicios externos.
